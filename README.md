# Emma DaSilva — Portfolio

Fresh start on `trunk`. Next.js + TypeScript + React, with Three.js and React Three Fiber available for a future interactive headphone scene.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Direction

- French by default; English translation planned.
- Dark-only palette: `#0A121A`, `#1F3F4D`, `#5D8FA6`, `#9FC8D9`, `#D6EAF2`.
- Planned one-page structure: Accueil, À propos, Compétences, Contact.
- No projects, university details, freelance advertising, or tech-stack logos.
- Headphone model is not yet committed. Planned path: `public/models/headphones.glb` (provided separately).

The current page is a clean temporary starting point, **not** the final portfolio design.
